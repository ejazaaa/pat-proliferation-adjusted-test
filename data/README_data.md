# Data in this repository

Only derived or otherwise unavailable tables are deposited here. Raw expression
and clinical matrices are not redistributed; use the accessions below.

| Source | Accession | Note |
| --- | --- | --- |
| SEQC | GSE62564 | RNA-seq, log2 RPM, 498 patients |
| Kocak | GSE45547 | Agilent array, 649 patients; survival annotation is NOT in GEO |
| NRC | GSE85047 | Affymetrix exon array, 283 patients |
| DepMap | Public 26Q3 | depmap.org, registration required |
| Platform annotation | GPL5175, GPL16876 | GEO platform pages |
| RefSeq to symbol | UCSC refGene, hg19 | hgdownload.soe.ucsc.edu |

`TableS7_Kocak_clinical.csv` contains survival data exported from the R2
platform (r2.amc.nl), which is not recoverable from GEO alone, and is the one
file here that others cannot reconstruct without repeating that export.
